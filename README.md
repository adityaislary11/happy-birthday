# A Little Birthday Love

A standalone, responsive birthday website in a playful cartoon style, using midnight navy, baby pink, cream, and pastel accents.

## Files

```text
birthday_love_project/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── images/
        ├── image-1.svg   (add later)
        ├── image-2.svg   (add later)
        └── image-3.svg   (add later)
```

The three SVGs are intentionally not included. When you have them, place them in `assets/images/` with exactly those names. The page shows a labelled placeholder until each image exists.

## Add photos

- **Permanent site image:** add your SVG to `assets/images/` and keep the matching filename above. The browser will load it automatically.
- **Temporary preview:** tap **Choose a photo** in a placeholder. It previews the chosen image in your browser only; it does not upload or save it into the project.

## Personalise it

In `index.html`, find the comments `Write your own birthday letter`, `Add a caption`, and `Write your own birthday wishes`. Add your own text inside the matching empty areas. The letter, captions, wishes, and closing message are deliberately left blank.

## Run it

Open `index.html` in a browser, or publish this folder as a separate static site. No build tools or package installation are required. Google Fonts are optional; the page has fallback fonts if you are offline.
